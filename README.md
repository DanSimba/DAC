## 🩸 BEM-VINDOS AO BANTADS!

Você já imaginou como seria a vida financeira dos monstros mais estilosos do mundo?

Pois é, até vampiros precisam pagar boletos. Lobisomens têm despesas com alimentação, múmias precisam declarar seus bens e Frankenstein aparentemente não consegue manter o crédito em dia.

Apresentamos o **BANTADS**, o banco oficial dos estudantes de Monster High!

Desenvolvido para atender às necessidades financeiras da população sobrenatural, nosso sistema oferece tudo o que um monstro precisa para administrar sua fortuna (ou os míseros 3 centavos que sobraram depois da última ida ao shopping).

Este projeto foi desenvolvido como trabalho acadêmico da disciplina **DS152 — Desenvolvimento de Aplicações Corporativas**, utilizando arquitetura de microsserviços e tecnologias modernas.

Porque até a morte é certa, mas deixar a conta bancária desorganizada é uma escolha.

## 🦇 WHAT'S YOUR MONSTER TYPE?

Aqui, cada criatura tem seu espaço. Afinal, inclusão financeira também é coisa de monstro!

### 💗 Monster Client — Área do Cliente

- **Autocadastro:** porque até monstros recém-criados precisam de uma conta.
- **Login e Logout:** entre no sistema. Sair dele é opcional, pagar as contas não.
- **Dashboard:** acompanhe sua fortuna antes que ela desapareça misteriosamente.
- **Depósitos:** adicione dinheiro à sua conta. Até vampiros precisam de uma renda.
- **Saques:** retire seu dinheiro antes que alguém o transforme em pó.
- **Transferências:** envie dinheiro para seus amigos. Amizade verdadeira é dividir até a dívida.
- **Extrato bancário:** descubra para onde foi todo aquele dinheiro. Provavelmente foi para o Monster High Mall.

### 🕷️ Monster Manager — Área do Gerente

Nem todo monstro nasceu para ser assustador. Alguns nasceram para trabalhar no administrativo.

- **Dashboard administrativo:** monitore o caos financeiro da instituição.
- **Aprovação de clientes:** decida quem está apto a entrar para nossa comunidade bancária.
- **Rejeição de clientes:** nem todo monstro merece um cartão de crédito.
- **Consulta de clientes:** saiba quem está nadando em ouro e quem está devendo até a alma.
- **Gerenciamento de gerentes:** até os monstros precisam de supervisão.
- **Relatórios:** porque até o apocalipse precisa de prestação de contas.

## ⚰️ THE DARK SIDE OF TECHNOLOGY

Por trás de toda essa monstruosidade fashion existe uma arquitetura muito bem estruturada.

O BANTADS utiliza uma arquitetura distribuída baseada em **Microsserviços**, garantindo a separação de responsabilidades e a comunicação entre os diferentes componentes da aplicação.

### 🧪 Nossa poção tecnológica

| Categoria | Tecnologia |
|---|---|
| Front-end | Angular / React / Vue.js |
| API Gateway | Node.js |
| Back-end | Java + Spring Boot |
| Banco de dados | PostgreSQL |
| Autenticação | MongoDB |
| Cache | Redis |
| Mensageria | RabbitMQ |
| Containerização | Docker |
| Segurança | JWT |

### 🕸️ Dark Architecture

- Microservices Architecture
- API Gateway
- Database per Service
- CQRS
- Event Sourcing
- SAGA Orchestration
- API Composition
- REST API
- Comunicação assíncrona com RabbitMQ

Porque se tem uma coisa pior que um vampiro sem sangue, é um microsserviço sem comunicação.

## 🧛 THE MONSTER FAMILY

Nosso pequeno ecossistema sobrenatural é composto por serviços independentes, cada um com sua própria responsabilidade.

| Microsserviço | O que faz |
|---|---|
| MS Auth | Cuida das identidades e autenticação dos monstros |
| MS Cliente | Gerencia os clientes e suas informações |
| MS Conta | Cuida do dinheiro, depósitos e movimentações |
| MS Gerente | Administra os responsáveis pelo banco |
| API Gateway | Porteiro da mansão. Nenhuma requisição entra sem passar por ele |
| SAGA | Impede que uma transação incompleta transforme o banco em um cemitério |
| MS Email | Envia mensagens importantes. Inclusive aquela notícia terrível de que seu saldo acabou |

## 💀 SAGA: SPELLS AND COMPENSATIONS

Nem toda magia sai como planejado.

No universo dos microsserviços, operações distribuídas podem falhar. Para lidar com esses problemas, utilizamos o padrão **SAGA**, coordenando transações e executando ações compensatórias quando necessário.

Afinal, se alguma coisa der errado, precisamos desfazer o estrago antes que a diretora Bloodgood descubra.

**Rollback?** Muito humano.

**Compensação?** Muito mais monstruoso.

## 🧟 HOW TO SUMMON THE PROJECT

Quer invocar essa monstruosidade na sua máquina?

Primeiro, clone o repositório:

```bash
git clone https://github.com/DanSimba/DAC.git
```

Entre na pasta:

```bash
cd DAC
```

Configure suas variáveis de ambiente utilizando o arquivo `.env.example`.

E finalmente invoque os containers:

```bash
docker compose up --build
```

Aguarde os serviços subirem e voilà! Sua própria instituição financeira sobrenatural estará pronta para funcionar.
